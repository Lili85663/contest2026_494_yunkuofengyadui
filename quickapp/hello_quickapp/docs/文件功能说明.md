# 文件功能说明

## 初学者先看这里

改界面打开 `src/pages/index/index.ux`；改计时打开 `src/common/focusPlan.js`。保存后运行 `bash scripts/build-app.sh`，再执行 `bash scripts/deploy-app.sh`。不是编译当前编辑的单个文件。

运行时，模拟器执行安装后的 RPK；MiMo 功能另外依赖 Ubuntu 上的本机服务。源码、测试和文档不会全部在手表里逐个运行。

## 哪些可以清理

停止编译后，可删除自动生成的 `build/`、`build-deploy.*`、`build-contest.*` 和 Python `__pycache__/`。`node_modules/` 可重装，删除后先运行 `npm ci`。不要删除 src、scripts、package.json、package-lock.json 或许可证。tests 不参与手表运行，但默认构建会调用，必须保留。

本次已移除旧说明文档、旧 RPK、旧截图、未使用的表带绘图脚本、旧独立健康探针工程及旧系统 defconfig；诊断功能保留在 tests。没有改写主业务或替换已验证接口。

密钥位于 Ubuntu 的 `~/.config/wrist-rhythm/mimo.json`，不在本包中。用户运行数据在设备存储中，也不随源码交付。不要为了清理工程删除这两个位置。
